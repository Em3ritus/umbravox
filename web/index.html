CYD — controller + collector

The NM-CYD-C5 with the display: scans WiFi/BLE, maps with GPS, logs WiGLE CSV to SD, and collects from the mesh. Flash this one first.

Use desktop Chrome, Edge or Opera. This page must be served over HTTPS.

Node — headless scanner

Any ESP32-C5 as an extra radio reporting to the mesh. No display, no GPS — it adds channel coverage.

Use desktop Chrome, Edge or Opera.

Coordinator — mesh tier

The optional middle tier that splits the spectrum across coordinators to scale toward ~12 co-located nodes.

Use desktop Chrome, Edge or Opera.

Theme designer

Design your own look for the CYD — colours, centrepiece picture, sweeps — preview it with the real device drawing code, and put it on the SD card. Themes are plain data files; they add no radio features.

Open the designer

How: plug the board in by USB, click Flash, and pick its serial port. A desktop Chromium browser (Chrome, Edge, Opera) over HTTPS is required — Web Serial does not exist in Firefox or Safari, or on phones.

Node boards: some newer C5 silicon (eco3) needs --no-stub flashing the browser tool can't do. If a node stalls at the first write, flash it over USB with PlatformIO instead (pio run -e nm-c5-node -t upload). The CYD flashes from the browser without trouble.

Private network: a browser-flashed node joins the open network out of the box. To add it to an isolated fleet with no crosstalk from other setups, open the CYD's MESH screen, tap ENROLL, and power the node up in range — it adopts your network and locks to it. No custom build needed.

Passive by design: UMBRAVOX only listens — no transmit-side tooling. See the project README for what it does and how to build it yourself.
