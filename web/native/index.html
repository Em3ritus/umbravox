Install umbravox

Connect your board by USB. Choose its exact model, connect, then install. No compiler or command line required. Use desktop Chrome or Edge.

1. Choose your board

These images are for display boards with at least 16 MiB flash. XIAO and radio-only nodes are not included.

Download firmware ZIP and instructions

First installation replaces the partition table with two 6 MiB application slots. Existing internal filesystem data may become inaccessible. External SD files are not written. No full-chip erase is performed.

Select a board to begin.

Connection log


If the board will not connect
  1. Use a USB data cable and close other serial monitors.
  2. Hold BOOT, press and release RESET, then release BOOT.
  3. Click Connect and select that board’s serial port. NM uses its CH340 USB connection.
Installation does not restart the board automatically. After all four images verify, press RESET (without holding BOOT) to start it.
NM native UI is build-tested; physical NM display/touch acceptance is still pending. Waveshare images use the accepted bce092c baseline. Browser installation itself still needs a physical-board acceptance run.
