# Built-in designer fonts

Each BDF here is the upstream file, unmodified, downloaded 2026-11-17. The licence was read from the upstream
repository's own licence file (copied into `licenses/`), not assumed. `tools/bdf2fnt.mjs` converts these to the
device's `.fnt` format when the designer is assembled; a theme pack carries only the converted sizes it uses.
