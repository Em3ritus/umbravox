      What is going onto the card

      Or install over USB, with the card left in the CYD

      Plug the CYD into this computer with its USB cable. The page sends the pack down the cable and the CYD writes it to its own card.

      1  Connect

      Connecting may reset the board. If it restarts, it is back in a few seconds; the page waits for it to finish booting before it sends anything.

      Close any serial monitor (Arduino IDE, PlatformIO, screen) first: only one program can use the port at a time.

        Over USB this page can only list /themes and write theme.json and emblem.bin into one pack folder. By design it cannot delete anything on the card or restart the board: those device commands act without asking, so a web page never sends them. To delete a pack or reboot from a computer, use tools/sdput.py.

        Browsers: this page needs Chrome 123+, Edge 123+, Safari 17.2+ or Firefox 138+ (its code is loaded as modules that import JSON). Installing straight onto the card needs a Chromium desktop browser (Chrome or Edge); Firefox and Safari get the zip download, and you copy the folder to the card by hand.

        Passive by design: a theme only changes how UMBRAVOX looks. It adds no radio features.
