# SLICK

Personal theme for slickrick773: dark charcoal, electric blue, silver.
Wi-Fi remains pink, 5 GHz cyan, BLE green; amber/red retain warning meanings.
Header: SLICK. Existing heptagram, radar default, lock-on alert presentation.

Copy this folder to `/themes/slick/` on the SD card, reboot to discover it,
then select SLICK under Display > Appearance. No firmware asset is required.
This pack does not enable portrait mode. Its palette also works in landscape.

Validated with the production theme parser; no status-color sanitization required.
`sim/portrait_theme_preview.cpp` generates the current landscape SCAN render
and separately labeled portrait design studies, with fixture readings.
