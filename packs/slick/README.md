# SLICK

Personal theme for slickrick773: charcoal, orange sweep/diamond, silver text.
Wi-Fi stays pink, 5 GHz cyan, BLE green. Warning colors retain their meanings.
The native header badge is separate from the Menu button. The clean field has
three rings, a crosshair, square contacts and a fading 45-degree radar trail.

Install this folder at `/themes/slick/`, reboot to discover it, then select SLICK
under Display > Appearance. Requires firmware supporting `centrepiece: radar`
and `badge: diamond`; older firmware rejects the unknown centrepiece safely.
No emblem bitmap or built-in theme ID is required. This pack does not enable
portrait mode. Portrait previews remain host-only design studies.

Validated with the production parser; no status-color sanitization required.
`sim/portrait_theme_preview.cpp` exports production landscape renders and separately
labeled portrait concepts, including 72 animation frames. Values are fixtures.
